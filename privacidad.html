Datos y autorización

Política de privacidad

Esta política describe el uso de datos de Momentazo LAB VPS, una aplicación privada operada por el titular del canal Momentazo LAB para gestionar su propio contenido.

Datos que utiliza

  • Identificador, nombre y datos del canal necesarios para comprobar que la autorización corresponde al destino configurado.
  • Archivos de vídeo, títulos, descripciones, etiquetas y estados de subida o procesamiento gestionados por la aplicación.
  • Estadísticas del contenido del canal: visualizaciones, interacción, suscriptores y duración o porcentaje de reproducción, cuando YouTube las proporciona.
  • Credenciales OAuth, incluido el token de renovación, necesarias para mantener la conexión autorizada con Google.

No se solicita acceso al correo, contactos o archivos privados de Google Drive para esta función. Los permisos solicitados son lectura de YouTube, subida de vídeos y lectura de YouTube Analytics.

Finalidad y uso limitado

Estos datos se utilizan para identificar el canal, publicar su contenido autorizado, verificar las subidas y analizar el rendimiento del propio canal. No se venden ni se utilizan para publicidad dirigida, elaboración de perfiles ajenos a esta función o entrenamiento de modelos generales de inteligencia artificial.

El uso y la transferencia de información recibida de las API de Google se ajustan a la Política de Datos de Usuario de los Servicios de API de Google, incluidos sus requisitos de uso limitado.

Proveedores y publicación

Google recibe los vídeos y metadatos necesarios para las subidas solicitadas a YouTube y facilita la autorización y las estadísticas. Los vídeos publicados y sus metadatos públicos pueden ser vistos según la visibilidad elegida por el titular.

El acabado editorial puede utilizar Gemini para analizar imágenes de fuentes públicas o autorizadas y generar guiones y voz. No se envían a ese proceso los tokens OAuth ni las estadísticas privadas de YouTube Analytics. El alojamiento del VPS y el alojamiento de esta web procesan los datos técnicos necesarios para prestar sus servicios.

Almacenamiento y conservación

Las credenciales OAuth se guardan en archivos privados del VPS. Las copias de seguridad de configuración, credenciales y datos del trabajador se cifran. Los registros operativos utilizan identificadores y códigos de estado; no deben contener contraseñas ni tokens.

Los vídeos, metadatos, estadísticas y registros pueden conservarse mientras sean necesarios para operar el canal y recuperar el sistema. La limpieza de material rechazado y la retención de copias de seguridad se configuran en el servidor. El titular puede eliminar los datos locales y sus copias según esas necesidades.

Revocación y eliminación

El titular puede revocar el permiso de la aplicación desde las conexiones de su cuenta de Google. La aplicación dejará de tener acceso cuando Google invalide la autorización. También puede detener el trabajador y eliminar las credenciales y los datos almacenados en su VPS. Revocar el acceso no elimina por sí solo vídeos ya publicados en YouTube; estos se gestionan en YouTube Studio.

Esta web y contacto

Esta web no incorpora formularios, publicidad ni herramientas de analítica propias. El proveedor de alojamiento puede conservar registros técnicos de las visitas. Para consultas sobre la aplicación o sus datos, utiliza el correo de asistencia mostrado en la pantalla de autorización de Google.
